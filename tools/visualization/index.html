Troubleshooting hints

  • When p99 rises: inspect thermal state, clock throttling, and power limits.
  • If mock backend is unexpectedly active, confirm TensorRT runtime + model path.
  • For jitter, increase input batching or disable noisy background jobs.
  • Compare warmup and steady-state values; warmup-only spikes are expected.
